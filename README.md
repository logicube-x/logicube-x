> To recolor the snake itself to neon, edit `.github/workflows/snake.yml` and set:
> ```yaml
> - name: generate github-contribution-grid-snake.svg
>   uses: Platane/snk@v3
>   with:
>     github_user_name: logicube-x
>     outputs: |
>       dist/github-contribution-grid-snake-dark.svg?color_snake=%2339F5FF&color_dots=%23161B22,%230E4429,%23006D5B,%2300B4D8,%2339F5FF
